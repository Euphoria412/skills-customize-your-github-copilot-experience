# 📘 Assignment: Python Text Processing

## 🎯 Objective

Practice string manipulation, file input/output, and text analysis by building a Python program that reads a text file, processes words, and saves results.

## 📝 Tasks

### 🛠️ Read and Clean Text

#### Description
Write code to open the provided text file and prepare its contents for analysis.

#### Requirements
Completed program should:

- Open `sample-text.txt` and read its contents
- Convert the text to lowercase and remove punctuation
- Split the text into individual words
- Store the cleaned words for analysis

### 🛠️ Analyze Text Data

#### Description
Create functions that summarize the cleaned text and count word usage.

#### Requirements
Completed program should:

- Count total words and unique words
- Find the most common word and the longest word
- Display results clearly in the console

### 🛠️ Write Processed Output

#### Description
Save the processed text and analysis results to a new file.

#### Requirements
Completed program should:

- Write cleaned text or summary information to `processed-text.txt`
- Include word counts and sample transformed content
- Confirm successful file writing to the user
