# 📘 Assignment: Statistics with Python

## 🎯 Objective

Practice data analysis and statistical calculations using `pandas` and `numpy` by exploring a dataset, computing summary statistics, and interpreting results.

## 📝 Tasks

### 🛠️ Load and Explore Data

#### Description
Read the provided dataset into Python and inspect its structure so you can understand the variables.

#### Requirements
Completed program should:

- Load `sample-stats.csv` using `pandas`
- Display the first few rows of the dataset
- Show summary statistics for numeric columns
- Describe the meaning of at least two dataset columns

### 🛠️ Calculate Statistical Measures

#### Description
Use `numpy` and `pandas` methods to calculate key statistics and compare different variables.

#### Requirements
Completed program should:

- Compute mean, median, and standard deviation for at least two numeric columns
- Calculate a correlation value between two variables
- Identify any outliers or unusual values in the dataset
- Print the results clearly with labels

### 🛠️ Save and Interpret Results

#### Description
Export the statistical findings and explain what the data reveals.

#### Requirements
Completed program should:

- Save the analysis summary to `statistics-summary.txt`
- Include observed trends or insights from the data
- Explain one real-world question the dataset could help answer
