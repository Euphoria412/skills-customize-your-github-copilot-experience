# 📘 Assignment: Python Data Visualization

## 🎯 Objective

Learn how to create charts and graphs using Python visualization libraries by building a program that loads data, creates plots, and saves visual output.

## 📝 Tasks

### 🛠️ Load and Explore the Data

#### Description
Read a dataset from a file and inspect its structure to prepare for visualization.

#### Requirements
Completed program should:

- Load the provided CSV file into Python
- Show the first few rows of the dataset
- Calculate summary statistics for the key columns
- Explain the dataset in a short text output

### 🛠️ Create Visualizations

#### Description
Use a plotting library to visualize the data and compare different chart types.

#### Requirements
Completed program should:

- Generate at least two different chart types (e.g. line chart, bar chart, scatter plot)
- Label axes and add a title for each chart
- Save the plots as image files
- Use colors or legends to make the charts clear

### 🛠️ Interpret the Results

#### Description
Write brief observations about what the charts show and what trends the data reveals.

#### Requirements
Completed program should:

- Print at least two insights from the visuals
- Explain why the charts are helpful for understanding the data
- Save the analysis summary with the output files if possible
