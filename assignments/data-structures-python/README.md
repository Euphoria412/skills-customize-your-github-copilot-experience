# 📘 Assignment: Data Structures in Python

## 🎯 Objective

Learn how to use Python lists, dictionaries, sets, and tuples by building a program that stores, processes, and summarizes structured data.

## 📝 Tasks

### 🛠️ Lists and Data Collection

#### Description
Create a list of sample items and use list operations to add, remove, and inspect values.

#### Requirements
Completed program should:

- Define a list with at least five values
- Add a new item and remove an existing item
- Access elements by index and slice the list
- Print the updated list and its length

### 🛠️ Dictionaries and Lookup Data

#### Description
Use a dictionary to store related information and retrieve values by key.

#### Requirements
Completed program should:

- Create a dictionary with at least three key-value pairs
- Add one new key-value pair and update an existing value
- Retrieve values using dictionary keys
- Print the dictionary contents clearly

### 🛠️ Sets and Tuple Usage

#### Description
Work with sets to manage unique values, and tuples to store fixed data.

#### Requirements
Completed program should:

- Create a set from a list and show unique values
- Perform at least one set operation such as union or intersection
- Create a tuple with related values and access its elements
- Explain when to use a tuple instead of a list
